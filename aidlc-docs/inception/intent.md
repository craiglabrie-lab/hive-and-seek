# Intent statement

## Objective

Build Hive & Seek: a portable, evidence-minded career intelligence system whose specialized agents use an explicit career and decision-context ontology. Preserve why choices were made, challenge assumptions, and improve recommendations through user corrections and observed outcomes.

## Current deliverable

Establish folder structure, README, and non-code artifacts in the existing repository. Preserve project intent without importing personal career information or private conversation transcripts. Document AI-DLC as a proposed development method; do not install it or build the runtime now.

## Stakeholders

| Stakeholder | Need |
| --- | --- |
| Job seeker | Useful opportunities, truthful materials, reasoning transparency, control over actions |
| Project owner | Reviewable design, small pilot, flexible implementation choices |
| Future developer / development agents | Traceable requirements, contracts, evaluations, and decisions |

## Source of requirements

The project owner's design discussion and portable career architect concept establish the goals of decision context, shared knowledge, specialist coordination, challenge, evidence, and measured improvement. Detailed record conventions and workflow contracts in this scaffold are proposed elaborations. External AI-DLC documentation informs development adoption only.

## Core hypothesis

Explicit, versioned decision context and specialist critique can reduce repeated explanation and improve opportunity relevance while controlling cost and preserving user agency. Evaluate this against a simpler single-assistant workflow before scaling.
