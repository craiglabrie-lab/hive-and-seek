# Construction planning

Runtime implementation is deferred. This folder reserves a place for reviewed functional design and build evidence when implementation is authorized.

Entry inputs: reviewed requirements, actual user/pilot feedback, selected technology, data and permission boundaries, unit dependencies, budget, and executable acceptance strategy.

The first working slice should consume a synthetic profile and listing, preserve evidence/ontology versions, produce a fit report and truthful draft, receive critique, and stop at a review packet. Add tool integrations only after that flow works.

When a real AI-DLC runtime is adopted, use its own generated records and review mechanisms. Link the resulting records here; do not hand-author proof that an engine stage passed.
