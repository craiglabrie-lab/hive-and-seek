# Career ontology

This folder defines the shared career knowledge model. It contains definitions only; real candidate instances remain private.

- [Model](model.md): entities, relations, record metadata, and change rules.
- [Decision rules](decision-rules.md): constraints, preferences, uncertainty, and explanation.
- [Discovery template](../templates/career-discovery.md): inputs for the first private instance.
- [Evidence register](../templates/evidence-register.csv): claim-to-source mapping.
- [Ontology change record](../templates/ontology-change.md): controlled updates.

A folder of documents is a corpus. It becomes an ontology when its concepts and relationships are explicit enough to support consistent interpretation and decisions. The pilot uses a human-readable model; no formal ontology language or executable validator is selected.
