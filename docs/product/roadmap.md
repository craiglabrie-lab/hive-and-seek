# Roadmap

No delivery dates, budget, or platform commitments have been made.

| Milestone | Deliverable | Completion evidence | Current state |
| --- | --- | --- | --- |
| M0 Foundation | Repo structure, specifications, prompts, templates | Artifacts present and document checks complete | This scaffold |
| M1 Discovery and ontology | Private discovery profile, evidence register, ontology v1 | User-confirmed facts and preferences; open conflicts visible | Not started |
| M2 Guided pilot | One role category and one complete review packet using the nine-agent baseline | Separate relevant-agent handoffs, fit report, truthful draft, critique, approval record, outcome record | Not started |
| M3 Implementation design | Storage, execution, integration, budget, and permission choices | Accepted decisions, contracts, and evaluation plan | Proposed |
| M4 Working slice | Smallest executable end-to-end workflow | Real checks pass; ontology versions and evidence survive resume | Deferred |
| M5 Persistent specialist execution | Tool-backed agents and bounded recovery | Better measured value than guided baseline within budget | Deferred |
| M6 Expansion | Additional workflows and integrations for the existing nine agents | Measured need, explicit permissions, privacy review | Deferred |

M1 and M2 can be performed manually in an LLM; they do not require a new application. Actual external job research depends on available tools. No stage is complete merely because its template exists.

Preserve the original nine distinct agents through the guided pilot and implementation. Invoke only relevant agents for a task and reduce duplicate work through clear contracts. Any proposal to add, merge, or remove agents requires evidence, documented tradeoffs, and an explicit architecture decision approved by the project owner.
