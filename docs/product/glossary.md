# Glossary

| Term | Meaning in Hive & Seek |
| --- | --- |
| OD-MAS | Ontology-Driven Multi-Agent System: coordinated specialist roles using an explicit shared domain model |
| Ontology | Concepts and their relationships, with rules for interpreting them; not just a folder of documents |
| Decision context | The choice, why it matters, evidence, assumptions, alternatives, constraints, tradeoffs, and revisions |
| Career corpus | Private source materials such as resumes, accomplishments, listings, and interview notes |
| Hive logic | The project's coordination rules for shared context, handoffs, critique, and consolidation |
| Logical agent | A specialist responsibility that may be simulated in one conversation |
| Executing agent | A role instantiated by a real runtime with bounded tools, state, and execution |
| Orchestrator | Coordinator that routes work, controls shared-state updates, and composes results |
| Provenance | Source, author or actor, timestamp, verification state, and version behind a claim |
| Hard constraint | Explicit condition that prevents a recommendation unless the user changes or waives it |
| Preference | Weighted desirability criterion that can be traded off; not automatically a hard constraint |
| AI-DLC | AI-Driven Development Life Cycle; proposed workflow for building the product |
| ADR | Architecture decision record documenting a design choice and its consequences |
| Pilot | One bounded, reviewable career workflow used to test usefulness |
| Runtime | Software that actually executes roles, tools, state changes, and recovery |
