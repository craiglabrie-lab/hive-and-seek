# Evaluation

The repository defines expected behavior and measurement methods. No runtime evaluation has been executed.

- [Acceptance scenarios](acceptance-scenarios.md): material behaviors to verify manually in a guided pilot and later with executable fixtures.
- [Scorecard](scorecard.md): outcomes, quality, effort, and cost measures.
- [Worker-scaling protocol](worker-scaling.md): compare worker counts under frontier orchestration/economy routing before selecting production capacity; no results or optimal count asserted.
- [Traceability](../aidlc-docs/inception/traceability.md): requirement coverage.

Use synthetic fixtures for public engineering work. Real-person pilot results remain private. Record execution mode, input and ontology versions, model/provider where known, evaluator, date, observed result, and evidence before assigning pass/fail.
