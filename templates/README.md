# Reusable templates

Blank templates are safe to keep here. Fill them with real information only in a separate private workspace. Replace placeholders deliberately; do not treat a blank record as completed work.

| Template | Purpose |
| --- | --- |
| [Career discovery](career-discovery.md) | Goals, existing evidence, motivations, criteria, and why |
| [Evidence register](evidence-register.csv) | Claims, sources, verification, limitations |
| [Decision record](decision-record.md) | Context, alternatives, rationale, tradeoffs, revisions |
| [Ontology change](ontology-change.md) | Versioned updates and affected outputs |
| [Agent handoff](agent-handoff.md) | Ownership, context, findings, uncertainty, next step |
| [Job fit assessment](job-fit-assessment.md) | Separate capability, desirability, and evidence |
| [Approval record](approval-record.md) | Concrete action/payload authorization and result |
| [Outcome tracker](outcome-tracker.csv) | Observed stages, outcomes, and measures |

Use stable IDs from the [ontology model](../ontology/model.md). Markdown templates capture concise explanations; CSV templates provide empty headers for registers. Dates should include a timezone when time matters.
