# Portable prompt

[Hive & Seek Career Architect](hive-and-seek-career-architect.txt) is a platform-neutral persona for discovery and system design. Paste the master prompt into an LLM or configure an assistant where supported.

It is adapted for this project and contains no personal career profile. It does not install tools, execute separate agents, create persistent memory, or schedule work. The host must provide any browsing, file, account, or execution capabilities it uses.

The prompt describes guided product use, while [AGENTS.md](../AGENTS.md) governs repository changes. A future runtime should implement the reviewed [contracts](../agents/README.md) and [requirements](../aidlc-docs/inception/requirements.md), rather than treating a prompt alone as enforcement.
